Personal Event Bridge

Privacy policy

Prepared September 12, 2026

San Kim operates Personal Event Bridge for personal use. This notice describes the tool's Gmail access and processing.

Information accessed and purpose

With the account owner's consent, the tool reads Gmail mailbox history and message metadata, including sender and subject, to identify configured notification types. For matching messages, it reads notification text, message identifiers, timestamps and conversation links. Related local listing records and writing preferences provide context for reply suggestions.

The Google permission is mailbox-wide read-only access. Filtering is enforced by the tool. The tool does not send messages or modify email, labels or read status.

Processing and service providers

Google Cloud Pub/Sub delivers mailbox-change notifications containing the account email address and a history cursor. Those notifications do not contain message bodies. The configured subscription retains unacknowledged notifications for up to seven days.

The local subscriber sends matching message content and relevant context to OpenAI through the owner's Codex account to generate recommendations. Codex tasks and the local queue retain this content. OpenAI's processing and retention are governed by its applicable service terms, privacy policy and the owner's account controls. Creating a task on the Mac does not mean the model runs locally.

The bridge does not sell Google user data, use it for advertising, or perform model training. Use and transfer of Google user data must comply with the Google API Services User Data Policy, including its Limited Use requirements. The operator must configure connected services consistently with those requirements.

Storage and protection

OAuth credentials, the message queue and operational logs are stored in the owner's local application-support directory with restricted file permissions. Credentials and raw notification samples are excluded from the source repository. The bridge's queue has no automatic content-deletion schedule; records remain until the owner deliberately removes them. Codex keeps its own task records separately.

Control and deletion

The owner can revoke this tool's access through Google Account connections and stop the local service. Revoking access stops future authorized retrieval; it does not erase existing local queue entries, Codex tasks or service-provider records. Those must be removed separately through the relevant tools and account controls. Deleting operational state requires care to avoid unintentionally processing an old notification again.

This information website

This website has no forms, analytics scripts or mailbox data. Its hosting provider may process ordinary web-request information such as IP addresses as part of serving the pages.

Contact and changes

Use the developer contact shown on the Google consent screen for questions about this tool or its data handling. This notice must be updated when the tool's data practices change.
