A personal automation tool

Personal Event Bridge

Email notifications become reply suggestions for their owner to review.

Personal Event Bridge is operated by San Kim for personal use. It listens for Gmail mailbox events, selects configured notification types, and creates or continues a Codex task on the owner's computer.

The first workflow helps with Kleinanzeigen conversations. It combines a matching notification with the owner's relevant listing records and writing preferences to recommend a response. The owner decides whether to send anything.

How access works

The tool requests read-only Gmail access. Google's permission covers the mailbox; the tool's rules select the messages used for recommendations. It does not request permission to send, delete, relabel, or modify email.

Google Cloud delivers mailbox-change signals to a subscriber on the owner's Mac. Matching message content is processed by OpenAI through Codex to generate a recommendation. This is not an entirely offline AI system.

This website contains information about the tool. It offers no sign-up, mailbox connection, or access to private conversations.
